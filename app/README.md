# CardVault JP — Aplicação Angular (Trabalho 02)

Projeto Angular 22 baseado em NgModule (gerado com `ng new --no-standalone --routing --style=css --ssr=false`).

```bash
npm install
npx ng serve   # http://localhost:4200
npx ng build
```

Consulte o README da raiz do repositório para rotas, arquitetura e usuários de teste.
